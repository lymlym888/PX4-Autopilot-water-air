The fixed-linear MPC candidate selected from the offline study was implemented onboard as an independent PX4 shadow-mode module on the H743/PX4 platform. The module was integrated into the `matek_h743_dummy` firmware target and scheduled at 50 Hz using a lightweight work-queue task. In this configuration, the controller read real `vehicle_attitude` and `vehicle_angular_velocity` inputs and computed a bounded shadow correction through an internal diagnostic chain comprising raw, amplitude-limited, rate-limited, pre-gate, and post-gate quantities. To support future safety-filter integration while preserving the existing CADRC control chain, the module additionally subscribed in read-only mode to allocator-domain base-command signals (`hydro_servos`) and to the CADRC roll-torque provenance signal (`hydro_torque_setpoint`). A fail-closed safety gate was maintained throughout all onboard tests: no actuator or hydro command publication was introduced, all post-gate outputs remained zero, and active output was explicitly blocked because the actuator sign had not yet been independently confirmed.
